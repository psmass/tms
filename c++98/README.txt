Welcome to your first Connext DDS example! 

This Example, is being DEPRECATED. It was a first attempt at using OO methodology in factoring out DDS logic.
(it's a bit overdone/too complex and not OO enough)

See the Python example in this repository for a more OO approach and cleaner design.
Similar wrappers have been created for c++98 and c++11 in a repository called DDS-Data-model-Example/CommandResponse
 - All examples use waitsets and allow Content Filters to be installed on readers and allow for monitoring statuses
 - c++98 uses compiled data types and programatic instantiation of DDS entities
 - c++11 and python use dynamic data types and xml application creation

If interested, inquire to pschmitt@rti.com for access to the DDS-Data-model-Example repository.
